# Module Nettoyage et traitement éthique de données structurées destinées à un apprentissage

## Description
Une équipe data souhaite améliorer la performance d’un modèle d’IA existant en y injectant de nouvelles données. Toutefois, ces données brutes comportent plusieurs problématiques : certaines colonnes contiennent des informations sensibles à caractère personnel ou éthique (nom, prénom, sexe, poids, taille…), d’autres sont incomplètes ou erronées (valeurs manquantes, outliers, formats incohérents).
